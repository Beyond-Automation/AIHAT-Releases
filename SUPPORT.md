# AIHAT Support

## Before requesting help

1. Confirm you downloaded AIHAT from the [official release](https://github.com/Beyond-Automation/AIHAT-Releases/releases/tag/v1.2.0).
2. Confirm Windows displays **Verified publisher: Randall Lewis**.
3. Confirm you approved the UAC elevation prompt.
4. Review the [Installation Guide](INSTALLATION.md) and [User Guide](USER-GUIDE.md).
5. Re-run the audit and note the AIHAT version and exact error.

## Request support

Use the Beyond Automation contact page:

https://beyondautomation.io/contact

Include:

- AIHAT version
- Windows edition, version, and build
- A concise description of the issue
- Steps to reproduce
- The exact error message

Do not publicly post reports or logs without reviewing them first. They may contain computer names, local account names, IP addresses, and other sensitive infrastructure information.

## Security issues

Do not report vulnerabilities through a public issue. Follow [SECURITY.md](SECURITY.md).
